# Changelog

## 1.0.0

- Initial public release for Minecraft 1.21.1 on NeoForge.
- Adds a scrollable mod filter panel beside JEI's recipe viewer and creative inventory.
- Selecting a mod applies JEI's native `@modid` search filter.
- Adds clear and hide/show controls for the panel.
- Makes panel width, visibility, and spacing configurable through the client config.
- Removes duplicate filter entries for the Aeronautics add-on modules.
- Requires JEI 19.x and Java 21.
